# simple-cheat-dll
simple cheat dll that i used to test on minecraft bedrock single player this is very outdated and hasn't been updated in many months. all offsets and pointers can be found using cheat engine or ida.
this can only be used in single player since it doesn't manipulate packets which are used for multiplayer cheats on minecraft bedrock
should work on most single player games if code is adapted and can be used as a base to a project but is very simple 
use at your own risk since it uses windows api to modify the game which is detected by most anti cheats.

I did have examples of dll sideloading and a simple dll injector but was lost when i switched to linux
parts of code are inspired by guided hacking and I used their videos to learn the windows api and dll cheats
I do not plan on updating this project this is only uploaded here for future reference
